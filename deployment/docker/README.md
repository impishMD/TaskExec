# TaskExec containers

The root [Dockerfile](../../Dockerfile) builds server/runner targets. Job/helper
Dockerfiles live in this directory. All four variants publish to `impishmd/taskexec`
and `ghcr.io/impishmd/taskexec` with role suffixes for non-server variants.
