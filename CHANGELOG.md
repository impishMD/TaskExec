# Changelog

## [v1.0.6](release-notes/en/v1.0.6.md)

- Task dialog scrolling, footer spacing and responsive metadata/tab layout.
- Clickable failure statuses with multiline log diagnostics.
- Aligned template view controls and a dedicated Add role toolbar.
- Global and project Telegram test notifications without saving form changes.
- Helm chart 1.0.1 defaults to application v1.0.6.

## [v1.0.0](release-notes/en/v1.0.0.md)

- TaskExec branding, CLI/service/module, environment prefix and container images.
- Refreshed interface, contextual help, project icons and management settings.
- HashiCorp Vault authentication, field mapping and access-key references in variable groups.
- Global and project Telegram notifications.
- Kubernetes Helm chart and independently versioned chart release pipeline.
- Bilingual documentation, deployment examples and application release automation.

## [v0.0.1](release-notes/en/v0.0.1.md)

Initial independent release under the previous name, JEH (Job Executor Hub).
Established Docker Hub/GHCR publication, versioned binaries/packages, bilingual documentation
and removal of upstream agent artifacts.
