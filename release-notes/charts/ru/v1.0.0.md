# Helm-чарт TaskExec 1.0.0

Версия приложения: **v1.0.0**.

- Helm-чарт на основе Semaphore UI Charts: OIDC-провайдеры, сопоставление Kubernetes Secrets и собственные CA-сертификаты.
- Один сервер с постоянным томом для конфигурации и SQLite.
- Внешние PostgreSQL и MySQL, реквизиты из существующего Kubernetes Secret.
- Service, опциональные Ingress/TLS, публичный URL с подпутём и проверки здоровья.
- Сервер без root, исправление прав импортированного тома, сохранение и повторное использование PVC.
- Проверки Helm 3/4 и установка, обновление и сохранность данных в kind.

Установка: https://github.com/impishMD/TaskExec/blob/develop/docs/ru/helm.md
