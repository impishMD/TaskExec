# TaskExec Helm chart 1.0.0

Application version: **v1.0.0**.

- Single-server deployment with persistent configuration and SQLite storage.
- External PostgreSQL and MySQL, credentials from an existing Kubernetes Secret.
- Service, optional Ingress/TLS, public URLs with subpaths and health probes.
- Non-root server, optional volume ownership repair, retained or existing PVCs.
- Helm 3/4 validation and kind install/upgrade/persistence checks.

Installation: https://github.com/impishMD/TaskExec/blob/develop/docs/en/helm.md
