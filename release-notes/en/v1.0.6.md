# TaskExec v1.0.6

- Task execution dialogs have one log scroll area and a separate action bar with consistent spacing, including fullscreen and narrow screens.
- Task metadata and Log / Details / Summary tabs wrap without overlapping.
- Click a Failed status to view errors from the task log. The popup includes multiline diagnostics, uses recent log entries when no explicit error is found, and closes on a page click.
- Template view editing buttons align with the view tabs.
- The Add role button has its own toolbar above template permissions.
- Telegram settings include a Test notification button for global and project credentials. Tests use current form values without saving settings and report delivery results in the form.

Application version advances from v1.0.0 to v1.0.6 for these six changes.
