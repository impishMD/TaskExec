# TaskExec v1.2.0

- Project API tokens are available under Dashboard → Settings → API tokens for server administrators and project owners. Choose permissions, allowed templates, launch overrides and an expiry period. Tokens can be rotated or revoked; their secrets are displayed once and stored as hashes.
- Project tokens work independently of their creator's account until expiry or manual revocation. They are restricted to one project, and stopping tasks requires both permission and ownership by that token. Queued runs recheck token authorization before execution.
- Token creation, rotation and revocation are recorded in the audit log. Tasks show the project token that started them.
- Project settings use General, Notifications, API tokens and Danger zone tabs. Notification channels have their own tabs, with the corrected Telegram icon.
- Personal API tokens are in the profile menu below Edit account.
- The project-token interface has compact selections, clear expiry labels, All / Active / Revoked filters and a responsive table.
- Helm chart 1.0.4 defaults to application v1.2.0.

The database migration for project tokens runs automatically at startup. Existing personal tokens remain supported.
