# TaskExec v1.1.2

- Expanded option panels use consistent theme colors and clean rounded borders, without diamond-shaped pointers, across templates, schedules, integrations, surveys, views and user settings.
- Project notification settings have a close button. Test notification is on the left; Cancel and Save are grouped on the right, with wrapping on narrow screens.
- Project resource tables and settings use the available page width, including schedules, inventories, repositories, keys, variable groups, integrations, activity and team management.
- Helm chart 1.0.3 defaults to application v1.1.2.
