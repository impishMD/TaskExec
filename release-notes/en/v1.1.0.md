# TaskExec v1.1.0

- Project activity messages and task statuses follow the selected interface language, including existing records. Switching languages updates the activity table without reloading or rewriting history.
- Ansible Vault accepts String access keys as passwords alongside Login with password keys.
- New template forms show appropriate script or directory examples for Ansible, Python, PowerShell, Bash, Terraform, OpenTofu, Terragrunt and Pulumi.
- Releases reuse successful branch CI for the exact tagged commit instead of repeating the full race test suite and temporary container builds. Versioned images are published using their verified digests.
- Helm chart 1.0.2 defaults to application v1.1.0.
