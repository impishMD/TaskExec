# TaskExec v1.0.0

TaskExec is a self-hosted automation server for Ansible, Terraform, OpenTofu and scripts.

- Helm chart based on Semaphore UI Charts, with OIDC providers, Kubernetes Secret mappings and custom CA bundles.
- TaskExec identity across the application, CLI, packages, container images and environment variables.
- Refreshed interface, consistent dialogs, contextual help and configurable project icons.
- HashiCorp Vault KV v1/v2 storage with token, AppRole, Kubernetes, JWT and certificate authentication.
- Secret field mappings for strings, variable sets, username/password and SSH credentials.
- Variable groups with current access-key values, field references and environment-variable mappings.
- Management settings and global/project Telegram notifications.
- Native Linux/macOS binaries, Linux DEB/RPM packages and amd64/arm64 server, runner, job and helper images.
- Kubernetes deployment through the independently versioned TaskExec Helm chart.

Existing installations: follow the [migration guide](https://github.com/impishMD/TaskExec/blob/v1.0.0/docs/en/migration.md) and preserve
the database and encryption keys. The Helm chart uses a single server and persistent storage.
