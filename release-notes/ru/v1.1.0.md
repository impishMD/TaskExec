# TaskExec v1.1.0

- Сообщения активности проекта и статусы задач отображаются на выбранном языке интерфейса, включая старые записи. При смене языка таблица обновляется без перезагрузки и изменения сохранённой истории.
- В хранилищах Ansible Vault можно использовать ключи типа «Строка» как пароль, а также прежний тип «Логин с паролем».
- В новых шаблонах отображаются подходящие примеры файлов или каталогов для Ansible, Python, PowerShell, Bash, Terraform, OpenTofu, Terragrunt и Pulumi.
- Релиз использует успешный CI того же коммита: полный набор тестов с `-race` и временные CI-образы не запускаются повторно. Версионные образы публикуются по проверенным digest.
- Helm-чарт 1.0.2 по умолчанию устанавливает приложение v1.1.0.
