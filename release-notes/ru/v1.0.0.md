# TaskExec v1.0.0

TaskExec — сервер автоматизации для Ansible, Terraform, OpenTofu и скриптов.

- Helm-чарт на основе Semaphore UI Charts: OIDC-провайдеры, сопоставление Kubernetes Secrets и собственные CA-сертификаты.
- Название TaskExec в интерфейсе, CLI, пакетах, образах и переменных окружения.
- Обновлённый интерфейс, единое оформление диалогов, контекстная справка и иконки проектов.
- HashiCorp Vault KV v1/v2 с аутентификацией по токену, AppRole, Kubernetes, JWT и сертификату.
- Сопоставление полей секретов для строк, наборов переменных, логина/пароля и SSH-ключей.
- Группы переменных с актуальными значениями ключей доступа, ссылками на поля и передачей в окружение.
- Настройки управления и глобальные/проектные уведомления Telegram.
- Бинарные файлы Linux/macOS, DEB/RPM и образы сервера, исполнителя, задач и helper для amd64/arm64.
- Установка в Kubernetes через Helm-чарт с независимой версией.

Для существующих установок выполните [миграцию](https://github.com/impishMD/TaskExec/blob/v1.0.0/docs/ru/migration.md), сохранив базу
и ключи шифрования. Helm-чарт использует один сервер и постоянный том.
