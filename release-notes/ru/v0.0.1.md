# v0.0.1

Первый самостоятельный выпуск опубликован под именем JEH (Job Executor Hub)
на основе upstream-коммита `fc66be94`. Тег и артефакты сохраняют это имя.

В выпуск вошли CLI и конфигурация, образы Docker Hub/GHCR, архивы Linux/macOS,
пакеты DEB/RPM, документация на двух языках и проверки релизных сборок.
Сохранены авторство MIT и сведения о сторонних зависимостях.
