# TaskExec v1.2.0

- Проектные API токены доступны администраторам сервера и владельцам проекта в разделе «Панель управления → Настройки → API токены». Можно задать права, разрешённые шаблоны, изменяемые параметры запуска и срок действия, перевыпустить или отозвать токен. Секрет показывается один раз, в базе хранится только хеш.
- Проектные токены действуют независимо от учётной записи создателя до истечения срока или ручного отзыва. Доступ ограничен одним проектом; остановка разрешена только для задач, запущенных этим токеном, при наличии соответствующего права. Перед выполнением задач из очереди права токена проверяются повторно.
- Создание, перевыпуск и отзыв записываются в аудит. В задачах отображается запустивший их проектный токен.
- Настройки проекта разделены на вкладки «Общие», «Оповещения», «API токены» и «Опасная зона». У каналов оповещений отдельные вкладки; значок Telegram исправлен.
- Персональные API токены перенесены в меню профиля под пункт «Редактировать аккаунт».
- В интерфейсе проектных токенов уменьшены выбранные элементы, исправлены подписи срока действия, добавлены фильтры «Все / Активные / Отозванные» и адаптирована таблица для узких экранов.
- Helm-чарт 1.0.4 использует приложение v1.2.0 по умолчанию.

Миграция базы для проектных токенов выполняется автоматически при запуске. Персональные токены продолжают поддерживаться.
