# v0.0.1

[English](../../en/releases/v0.0.1.md) | **Русский**

Первый самостоятельный выпуск **Job Executor Hub (JEH)**.

- Новый логотип, favicon, оформление интерфейса и ссылки проекта.
- Новые имена бинарника, Go-модуля и службы; окружение `JEH_*`, метрики `jeh_*`.
- Образы server/runner/job/helper для Linux amd64/arm64 в Docker Hub и GHCR.
- Архивы Linux/macOS amd64/arm64, Linux DEB/RPM, исходники и контрольные суммы в GitHub Releases.
- CI и версионная публикация с runtime-проверками до обновления стабильных алиасов.
- EN/RU документация и генерируемые справочники конфигурации/CLI в репозитории.
- Удалены Claude-конфиги, агентские артефакты, upstream workflows и submodule документации.
- Сохранены MIT-авторство и сведения о сторонних компонентах.

## Установка

```sh
docker pull impishmd/jeh:v0.0.1
# Или: docker pull ghcr.io/impishmd/jeh:v0.0.1
```

Для первого запуска используйте [Compose](../README.md#быстрый-запуск),
для пакетов — [инструкцию Linux](../linux.md).
Дополнительные теги: `v0.0.1-runner`, `v0.0.1-job`, `v0.0.1-helper`.

## Совместимость

Новая нумерация JEH основана на upstream-коммите `fc66be94`.
Изменены префиксы окружения, команды, пути по умолчанию и метрики; старые префиксы
не являются алиасами. SQL-миграции и API/JSON-контракты сохранены.
Перед переносом сохраните БД, конфигурацию и ключи; следуйте [миграции](../migration.md).
Ребрендинг не добавляет SQL-миграций. Закрытые реализации Pro/Enterprise не включены.
