# Конфигурация

[English](../en/configuration.md) | **Русский**

JEH читает JSON/YAML и переменные `JEH_*`; переменные окружения имеют приоритет.
Создайте конфигурацию командой `jeh setup`, затем выполните
`jeh server --config /path/to/config.json`. Флаг `--no-config` позволяет использовать
только переменные окружения.

| Параметр | Назначение |
| --- | --- |
| `JEH_DB_DIALECT` | `sqlite`, `postgres` или `mysql` |
| `JEH_DB_HOST` | Файл SQLite или адрес сервера БД |
| `JEH_PORT` | HTTP-порт, по умолчанию 3000 |
| `JEH_WEB_ROOT` | Публичный URL с префиксом пути, если он есть |
| `JEH_TMP_PATH` | Рабочий каталог, по умолчанию `/tmp/jeh` |
| `JEH_ACCESS_KEY_ENCRYPTION` | Ключ шифрования секретов в base64 |
| `JEH_METRICS_ENABLED` | Метрики Prometheus |

Полный [справочник параметров EN](../en/reference/configuration.md),
[справочник CLI EN](../en/reference/cli.md), [схема](../../config.schema.yaml).
Ключ шифрования сохраняйте вместе с резервной копией: его замена делает старые секреты
недоступными. За обратным прокси укажите публичный URL. Доступны локальные учётные записи,
LDAP и OpenID Connect; параметры провайдеров перечислены в справочнике.

## Резервное копирование

Сохраняйте конфигурацию, ключи шифрования и базу вместе. Перед копированием файла SQLite
остановите экземпляр либо используйте согласованный backup SQLite. Для PostgreSQL/MySQL
применяйте штатные средства БД. Экспорт проекта в JSON не заменяет полную копию экземпляра.

## Доступность функций

v0.0.1 собирает открытый код репозитория. Пакет `pro` содержит заглушки интерфейсов,
а не закрытые реализации upstream. Отмеченные как **upstream Pro/Enterprise** параметры
сохранены для совместимости исходного кода и не включают соответствующие функции.
В частности, workflows, active-active HA, пользовательские роли и Docker/Kubernetes
исполнители остаются недоступными. JEH не продаёт и не активирует подписки;
сборка не скачивает закрытые модули upstream.
