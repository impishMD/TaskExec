# v0.0.1

**English** | [Русский](../../ru/releases/v0.0.1.md)

First independent release of **Job Executor Hub (JEH)**.

- New JEH logo, favicon, interface branding and project links.
- Renamed executable/module/service, `JEH_*` environment variables and `jeh_*` metrics.
- Native Linux amd64/arm64 images in Docker Hub and GHCR: server, runner, job and helper.
- GitHub archives for Linux/macOS amd64/arm64, Linux DEB/RPM packages, source and checksums.
- Versioned releases, CI and publication with runtime smoke tests before stable aliases update.
- English/Russian documentation and generated configuration/CLI references within the repository.
- Removed Claude configuration, agent artifacts, upstream publishing jobs and docs submodule.
- Preserved MIT copyright and third-party attribution.

## Install

```sh
docker pull impishmd/jeh:v0.0.1
# Or: docker pull ghcr.io/impishmd/jeh:v0.0.1
```

Use the [Compose quick start](../../../README.md#quick-start) for initial configuration,
or follow the [Linux guide](../linux.md). Other image tags are `v0.0.1-runner`,
`v0.0.1-job` and `v0.0.1-helper`.

## Compatibility

This is a new product/version series based on upstream commit `fc66be94`.
Environment prefixes, executable names, default paths and metrics change; old prefixes
are not aliases. Existing SQL migrations and API/JSON contracts are retained.
Back up the database, configuration and encryption keys before moving an installation;
follow [Migration](../migration.md). No new SQL migration is introduced by the rebrand.
Upstream proprietary Pro/Enterprise implementations are not included.
